## Instalação e Execução
Para compilar e executar o arquivo `Aula03.cpp`, você precisará de um compilador C++ (como g++).

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/HSaimon/test.beta.git
   cd test.beta
   ```

2. **Compile o código:**
   ```bash
   g++ Aula03.cpp -o Aula03
   ```

3. **Execute o programa:**
   ```bash
   ./Aula03
   ```
